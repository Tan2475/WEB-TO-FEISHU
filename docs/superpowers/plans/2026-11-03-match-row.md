# 按字段匹配更新行

用户确认：按抓取字段值匹配已有行，找到更新，找不到新增。

设计：每条规则新增可选 matchField（飞书列名），留空保持追加模式。比较去除首尾空白后的完整值，区分大小写；匹配值不能为空，重复匹配拒绝写入。更新仅提交成功提取的字段，保留其他列与抓取失败的旧值。适用 Sheets、Bitable 及其 Wiki 链接。

实施顺序：
- [x] 先写匹配、新增、重复、空值、分页、失败以及配置导入导出回归用例。
- [x] 实现 Sheets 分段查列、稀疏更新和同一行截图写入；Bitable 分页查找与更新记录。
- [x] 配置输入、保存/复制/导入导出、popup 到后台参数传递和结果提示。
- [x] 测试、构建、语法检查与独立审查。

无新增依赖；沿用已有 UI 样式（未发现独立 UI 规范）。不执行真实飞书写入。

验证：49 个测试通过，9 个 JS 文件语法检查及 npm run build 通过。独立审查发现的邮箱、多选数组和公式结构问题均已用失败回归验证后修复；富文本内部空白与重复表头也有覆盖。浏览器模拟 Chrome 存储验证保存、复制、导出和覆盖导入，截图确认布局。API 行数/分页结构核对飞书官方 SDK；字段类型核对官方 larksuite/openclaw-lark 记录值说明。
