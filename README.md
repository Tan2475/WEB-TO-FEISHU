# Web To Feishu (网页万能抓取到飞书)

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.1.0-green.svg)

一个强大的、高度可定制的 Chrome 浏览器扩展。无需编写代码，即可通过**可视化拾取**提取任意网页数据，并一键推送到**飞书多维表格 (Bitable)**、**飞书电子表格 (Sheets)** 或 **飞书知识库 (Wiki)**。

## ✨ 核心特性

- **🎯 零代码可视化拾取 (Visual Picker)**
  - 内置元素拾取器，鼠标点击即可自动生成精准的 CSS 选择器。
  - 完全不需要打开浏览器的 F12 开发者工具。
- **✂️ 区域截图 (Region Screenshot)**
  - 在网页上拖拽框选任意区域，作为字段值写入飞书表格。
  - 区域以「锚点元素 + 相对偏移」记录，页面滚动或布局小幅变化后仍能准确复现。
  - 配置一次即可在后续抓取中自动重复执行，也支持临时重新框选。
- **🕷️ 动态抓取规则引擎**
  - 可以为单个域名配置无限套并行抓取规则。
  - 支持提取文本 (text)、链接 (href)、图片 (src)、输入框值 (value)、HTML 源码、当前网页 URL 及区域截图。
- **🖱️ 自动化预交互 (Pre-action)**
  - 完美解决“悬停或点击才加载”的现代前端框架节点。扩展可自动执行点击/悬停并在延时后抓取数据。
- **📊 全兼容飞书双表生态**
  - **多维表格 (Bitable)**：自动组装结构化 JSON 追加任意记录；截图以附件形式上传并关联。
  - **电子表格 (Sheets)**：智能读取首行作为表头映射，无需关心列序号，自动追加末尾行并把截图写入对应单元格。
  - **知识库组件 (Wiki)**：自动调用 API 解析知识库底层的真实文件类型及 Token。
- **🔒 纯本地架构，确保隐私**
  - 没有第三方中间服务器。你的飞书 `App ID` 与 `App Secret` 仅仅保存在浏览器的本地存储 (`chrome.storage.local`)，扩展直接与飞书 Open API 通信。
- **💾 配置导出与导入**
  - 一键把抓取规则备份成 JSON，换设备或交给同事直接导入，凭证是否随包导出由你决定。

## 🚀 安装指南

本仓库已包含编译好的样式产物 `dist/tailwind.css`，**克隆后即可直接加载，无需任何额外构建**：

1. 克隆或下载本仓库代码到本地。
2. 打开 Chrome (或 Edge) 浏览器，进入扩展管理页面 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择本项目的**根目录**（即包含 `manifest.json` 的目录，**不要**选 `dist` 或其它子目录）。

> 💡 **修改样式后需要重新编译**：本项目使用 **Tailwind CSS v4**（需 **Node.js 20+**）。如果你改动了 `src/styles.css` 或 `tailwind.config.js`，请运行：
> ```bash
> npm install
> npm run build   # 一次性编译；开发时可用 npm run watch 开启监听
> ```
> 编译产物会输出到 `dist/tailwind.css`，该文件已被纳入版本库以支持“开箱即用”。

## 💡 使用教程

1. **配置飞书凭证：**
   - 点击扩展图标，然后在弹窗中点击右上角的 **“设置 ⚙️”** 进入选项页。
   - 填入您的飞书企业自建应用 `App ID` 和 `App Secret`（需开启相应的多维表格/电子表格/知识库的读写权限）。
   
2. **创建抓取规则：**
   - 在选项页点击 **“新增站点规则”**。
   - 输入 **“匹配 URL 关键字”**（例如 `xiaohongshu.com`）。
   - 在“提取字段”列表中，填入飞书的列名，并点击 **[ 🎯 拾取 ]** 按钮在网页上直接框选你想要的元素。

3. **配置区域截图字段（可选）：**
   - 新增一个字段，把“提取类型”切换为 **截取指定区域截图**。
   - 点击按钮变为 **[ 🖼 框选区域 ]**，点击后扩展会切到目标网页，拖拽框选出需要截图的区域（`Esc` 取消）。
   - 框选完成后输入框会回显 `已框选 宽 × 高`，回到配置页点击 **保存全局配置** 即可。
   - 若网页改版导致区域偏移，重新点击框选覆盖即可；临时想换区域而不改规则，可在插件弹窗的「区域截图字段」中点击 **重选**（仅本次生效，重新保存规则后失效）。

4. **一键提取数据：**
   - 浏览任意符合该关键字的网页。
   - 点击浏览器右上角的插件图标，在下拉框中选择你想使用的规则。
   - 输入或粘贴你想要推送的**目标飞书表格完整链接**。
   - 点击**提取数据**，扩展会先抓取文本字段，再逐张定位并截取区域截图，在弹出预览框确认数据无误后，点击**最后确认写入**。

> 📸 **截图字段对目标列的要求**：多维表格中该列必须是**附件**类型；电子表格中按首行表头名匹配列，图片会写入当次新增行的对应单元格。

## 💾 配置导出与导入

规则配好之后可以备份成 JSON，换电脑或发给同事都不用重配。入口在选项页右上角的 **⬇ 导出配置** / **⬆ 导入配置**。

**导出**

- 数据取自当前页面，**包含尚未点击“保存全局配置”的修改**，可以先导出再保存。
- 凭证默认**不导出**。需要连同 `App ID` / `App Secret` 一起带走时，手动勾选「包含飞书凭证」——此时文件内是明文密钥，文件名会自动加 `-with-credentials` 后缀提醒，**不要上传到代码仓库或聊天群**。
- 生成的文件形如 `web-to-feishu-config-20261103-0941.json`。

**导入**

- 选文件后先显示摘要（规则数、字段数、是否含凭证、导出时间），再选合并方式：
  - **追加导入**：保留现有规则，把导入的接在后面，重名自动加 `(导入)` 后缀；不改动飞书凭证。
  - **覆盖导入**：清空当前全部规则；文件含凭证时一并写入凭证与目标表格链接。
- 导入前会做结构校验：非本扩展导出的文件、`schemaVersion` 过新、缺 `rules` 都会直接拒绝；脏字段（缺名称、缺选择器、截图区域不完整）会被丢弃，并在摘要里列明，不会静默吞掉。

导出走本地 `Blob` 下载、导入走 `File` 读取，**没有新增任何权限**。

## ⚠️ 已知限制

| 限制 | 说明 |
|---|---|
| 仅截取可视区 | 使用浏览器可视区截图能力，无法直接截取整页长图。跨屏区域会自动滚动后再截，超出视口部分会被截断并给出提示。 |
| 受固定元素遮挡 | 页面上的吸顶导航、悬浮客服等 fixed 元素若压在选区内，会一并被截入。 |
| 不可截图页面 | `chrome://` 开头的系统页、扩展页面、PDF 内嵌查看器不支持截图。 |
| 电子表格写入速度 | 每张截图独立调用一次写图接口，单张耗时约 0.3–1 秒；建议单规则内截图字段不超过 3 个。 |
| 表头列数上限 | 电子表格按首行 `A1:Z1` 读取表头，超过 26 列的字段不会被匹配。 |

## 📄 权限说明

扩展仅申请以下权限，不包含任何商业代码或后门，代码全透明，欢迎检查：

| 权限 | 用途 |
|---|---|
| `storage` | 在本地保存你的飞书 `App ID` / `App Secret` 与抓取规则（存于 `chrome.storage.local`）。 |
| `activeTab` | 在你点击扩展图标时，临时获得当前标签页的访问权限。 |
| `scripting` | 当目标页面尚未注入内容脚本时，按需注入以启动可视化拾取器。 |
| `host_permissions: "*://*/*"` | **抓取功能的核心**：抓取规则可指向任意网站，内容脚本必须能在目标页面上运行，才能拾取元素、读取 DOM。 |
| `host_permissions: "https://open.feishu.cn/*"` | 直接调用飞书开放平台 API 写入数据。 |

### 飞书应用需开启的权限

在飞书开放平台的应用后台按需勾选（截图功能对权限要求更高，缺权限会直接返回 `99991672` / `1061004` 等错误）：

| 使用场景 | 需要开通的权限 |
|---|---|
| 写入多维表格记录 | `bitable:app`（查看、评论、编辑和管理多维表格） |
| 电子表格写入文本 | `sheets:spreadsheet`（查看、评论、编辑和管理电子表格） |
| 电子表格写入图片 | 同上 `sheets:spreadsheet`，另需云空间 `drive:drive` |
| 多维表格上传截图附件 | 云空间 `drive:drive`（查看、评论、编辑和管理云空间中所有文件） |

> 扩展仅在点击时临时读取当前标签页画面（`chrome.tabs.captureVisibleTab`），截图数据不落盘、不上传到任何第三方，只在你点击“最后确认写入”时随记录一并提交给飞书。

> **为什么安装时会提示“读取和更改您在所有网站上的数据”？**
> 本扩展是一个**通用**网页抓取工具，抓取目标由你自行配置，理论上可以是任意域名。浏览器无法只对“未来才会配置的网站”单独授权，因此只能声明 `*://*/*`。
> 内容脚本**仅在你打开的目标页面**上执行 DOM 读取与元素拾取逻辑，**不会**收集、记录或上传你的浏览历史；
> 所有数据均由你的浏览器**直接与飞书开放平台 API 通信**，**没有任何第三方中间服务器**。
