# Web To Feishu (网页万能抓取到飞书)

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

一个强大的、高度可定制的 Chrome 浏览器扩展。无需编写代码，即可通过**可视化拾取**提取任意网页数据，并一键推送到**飞书多维表格 (Bitable)**、**飞书电子表格 (Sheets)** 或 **飞书知识库 (Wiki)**。

## ✨ 核心特性

- **🎯 零代码可视化拾取 (Visual Picker)**
  - 内置元素拾取器，鼠标点击即可自动生成精准的 CSS 选择器。
  - 完全不需要打开浏览器的 F12 开发者工具。
- **🕷️ 动态抓取规则引擎**
  - 可以为单个域名配置无限套并行抓取规则。
  - 支持提取文本 (text)、链接 (href)、图片 (src)、输入框值 (value)、HTML 源码 及 当前网页 URL。
- **🖱️ 自动化预交互 (Pre-action)**
  - 完美解决“悬停或点击才加载”的现代前端框架节点。扩展可自动执行点击/悬停并在延时后抓取数据。
- **📊 全兼容飞书双表生态**
  - **多维表格 (Bitable)**：自动组装结构化 JSON 追加任意记录。
  - **电子表格 (Sheets)**：智能读取首行作为表头映射，无需关心列序号，自动追加末尾行。
  - **知识库组件 (Wiki)**：自动调用 API 解析知识库底层的真实文件类型及 Token。
- **🔒 纯本地架构，确保隐私**
  - 没有第三方中间服务器。你的飞书 `App ID` 与 `App Secret` 仅仅保存在浏览器的本地存储 (`chrome.storage.local`)，扩展直接与飞书 Open API 通信。

## 🚀 安装指南

本仓库已包含编译好的样式产物 `dist/tailwind.css`，**克隆后即可直接加载，无需任何额外构建**：

1. 克隆或下载本仓库代码到本地。
2. 打开 Chrome (或 Edge) 浏览器，进入扩展管理页面 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择本项目的**根目录**（即包含 `manifest.json` 的目录，**不要**选 `dist` 或其它子目录）。

> 💡 **修改样式后需要重新编译**：本项目使用 **Tailwind CSS v4**（需 **Node.js 20+**）。如果你改动了 `src/styles.css` 或 `tailwind.config.js`，请运行：
> ```bash
> npm install
> npm run build   # 一次性编译；开发时可用 npm run watch 开启监听
> ```
> 编译产物会输出到 `dist/tailwind.css`，该文件已被纳入版本库以支持“开箱即用”。

## 💡 使用教程

1. **配置飞书凭证：**
   - 点击扩展图标，然后在弹窗中点击右上角的 **“设置 ⚙️”** 进入选项页。
   - 填入您的飞书企业自建应用 `App ID` 和 `App Secret`（需开启相应的多维表格/电子表格/知识库的读写权限）。
   
2. **创建抓取规则：**
   - 在选项页点击 **“新增站点规则”**。
   - 输入 **“匹配 URL 关键字”**（例如 `xiaohongshu.com`）。
   - 在“提取字段”列表中，填入飞书的列名，并点击 **[ 🎯 拾取 ]** 按钮在网页上直接框选你想要的元素。

3. **一键提取数据：**
   - 浏览任意符合该关键字的网页。
   - 点击浏览器右上角的插件图标，在下拉框中选择你想使用的规则。
   - 输入或粘贴你想要推送的**目标飞书表格完整链接**。
   - 点击**提取数据**，在弹出预览框确认抓取数据无误后，点击**最后确认写入**！

## 📄 权限说明

扩展仅申请以下权限，不包含任何商业代码或后门，代码全透明，欢迎检查：

| 权限 | 用途 |
|---|---|
| `storage` | 在本地保存你的飞书 `App ID` / `App Secret` 与抓取规则（存于 `chrome.storage.local`）。 |
| `activeTab` | 在你点击扩展图标时，临时获得当前标签页的访问权限。 |
| `scripting` | 当目标页面尚未注入内容脚本时，按需注入以启动可视化拾取器。 |
| `host_permissions: "*://*/*"` | **抓取功能的核心**：抓取规则可指向任意网站，内容脚本必须能在目标页面上运行，才能拾取元素、读取 DOM。 |
| `host_permissions: "https://open.feishu.cn/*"` | 直接调用飞书开放平台 API 写入数据。 |

> **为什么安装时会提示“读取和更改您在所有网站上的数据”？**
> 本扩展是一个**通用**网页抓取工具，抓取目标由你自行配置，理论上可以是任意域名。浏览器无法只对“未来才会配置的网站”单独授权，因此只能声明 `*://*/*`。
> 内容脚本**仅在你打开的目标页面**上执行 DOM 读取与元素拾取逻辑，**不会**收集、记录或上传你的浏览历史；
> 所有数据均由你的浏览器**直接与飞书开放平台 API 通信**，**没有任何第三方中间服务器**。
